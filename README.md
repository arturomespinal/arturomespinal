🧠 temporal-rag-tfm

Master's thesis: Retrieval-Augmented Generation for time series. A contrastive Transformer encoder + FAISS vector index acts as historical memory for forecasting and anomaly detection.

Stack: Python · PyTorch · FAISS · NT-Xent contrastive learning · cross-attention fusion
Results: −9.9% MAE on ETTh1 forecasting and F1 0.775 (+7.6%) on MSL anomaly detection vs. the parametric baseline
